# NOVARO — Premium Construction Products Marketplace

**Storefront name:** NOVARO (working name; domain and trademark clearance required). **Product/supplier brand:** ULTRA Chemicals, subject to authorization. The concept pictures are illustrative and are not genuine photos or label claims.

## Start
1. Extract this kit into the root of your React repository.
2. Open the project in Claude Code and paste `prompts/00_START_HERE.md`.
3. Approve and implement one milestone at a time. Use `CLAUDE.md` as the persistent instruction file.
4. For every subsequent page, create its visual, save in `designs/<page>/`, write spec in `docs/`, and update `docs/PAGE_REGISTRY.md` **before** coding.

This kit is a design and instruction package, **not a running storefront**. Before launch, supply accurate product catalog, approved product imagery, legal and contact details, locale/currency, fulfillment and payment provider. No invented product metrics or testimonials.
