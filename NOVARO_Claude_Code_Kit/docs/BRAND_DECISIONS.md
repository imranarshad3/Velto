# Naming choices

- **NOVARO** is a proposed customer-facing storefront name (not yet trademark/domain checked).
- **ULTRA Chemicals** remains the actual product/manufacturer brand where applicable. Do not relabel an ULTRA product with NOVARO on packaging or state NOVARO manufactures chemicals.
- Replace temporary NOVARO visual mock product packs with verified ULTRA photos and accurate catalog data before launch.
- The approved NOVARO design illustration includes *invented* popularity figures and packaging labels. Those are visual-only and should NOT be implemented as factual data.
- Name and logo can be revised later via `docs/DESIGN_SYSTEM.md`, tokens, and shared Header component.
